Built for how agents load plugins

Nothing more, nothing hidden. Six things it actually does.

01

One folder, any agent

Skills and MCP servers packaged together in a single directory. krate install and your agent can load it, no glue code required.

02

Verified installs

Every download is checked against the sha256 recorded at publish time. Tamper-evident by design, not by promise.

03

Your own namespace

Publish under @your-username. The server checks your token's owner against the scope on every publish. No overrides, no squatting.

04

Permanent versions

Semver, npm-style. Publish 1.0.0 once and it's locked in forever. Ship a fix by bumping the version, not by overwriting history.

05

Self-hostable

Same code as the hosted instance. docker compose up --build and you have your own registry: your namespace, your users, your data.

06

Free and open source

MIT licensed, no paid tier, no license key to enter. Use the hosted instance or run your own, it's the same code either way.

Up and running in three commands

No dependency resolution, no build system. Just download, verify, unpack.

01 Scaffold

Init and validate

krate init my-plugin
krate validate

Generate the manifest, add a skills/ folder or mcp.json, and validate it locally. No network involved.

02 Publish

Ship it under your scope

krate login
krate publish

Packs it into a .tar.gz and uploads it under your own @scope. The name and version come straight from plugin.json.

03 Install

Anyone can grab it

krate search my-plugin
krate install @you/my-plugin

Checksum verified, unpacked, and tracked in krate-lock.json.
